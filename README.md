## Featured Projects

### AOS / qp-gen: AI Question Paper Platform
Live at [hsatedu.in](https://hsatedu.in). Generates board-format question papers from educators' own PDFs.
- Streams generated questions into a TipTap editor where educators review and edit before PDF/DOCX export
- RAG over uploaded source documents (pgvector), kept separate from a blueprint engine that controls structure, marks and Bloom's levels
- Stack: Next.js, Django, PostgreSQL, TipTap, Zustand, AWS (Cognito, S3, RDS, EC2, Amplify)
- Repo: [qp-gen](https://github.com/Paardhu22/qp-gen)

### Triya Manager (client project)
Co-living/PG management platform built for Triya Hospitality Services: rent collections, deposits, notice periods, WhatsApp reminders.
- Stack: Next.js, Prisma, TypeScript, Tailwind, shadcn/ui, PostgreSQL

### Trinker: API security testing
Security checks you can review, run and replay.
- Repo: [trinker](https://github.com/Paardhu22/trinker)

### SELENO: Lunar image registration (SIH 2026, ISRO)
Pipeline that aligns Chandrayaan-2 imagery with lunar reference maps across sun-angle and scale differences.
- Stack: Python, FastAPI, React
- Repo: [seleno-prototype](https://github.com/vegadarsiwork/seleno-prototype)

### Renaut: AI app synthesis
Describe an app in a prompt; a multi-agent pipeline builds it in E2B sandboxes with a live preview.
- Stack: Next.js, Inngest Agent-Kit, E2B, Prisma
